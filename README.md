# 留余 · 个人财务管家

一个以「保护现金流」为核心的大学生个人财务 PWA。零依赖、Mobile-first，数据全部保存在你自己的浏览器本地（Local Storage），不会上传到任何服务器。

## 在线使用

打开：https://ja3512256262-maker.github.io/liuyu-app/

手机建议添加到主屏，用起来跟原生 App 一样：

- **iPhone**：用 Safari 打开 → 分享按钮 → 添加到主屏幕
- **安卓**：用 Chrome 打开 → 右上角菜单 → 添加到主屏幕

添加到主屏后支持离线打开（Service Worker 缓存了应用外壳）。

## 功能

- 快速记账（金额、用途、分类、计划性、必要性、效用、冲动程度）
- 预算管理：月预算硬约束、剩余日预算、使用率
- 账本：筛选（今天 / 本月 / 全部 / 回收站）、编辑、软删除与恢复
- **月份切换**：可查看任意有记录的月份，首页与各报表同步跟随
- 每日报告（S/A/B/C/D/E 评级）、月度报告（8 个复盘问题）
- 大额消费审核（≥¥100 且计划外，24 小时 / 3 天 / 7 天冷静期）
- 未来大额计划与建议每月储备
- 长期趋势（3 / 6 / 12 个月可视化）
- 数据导出：JSON、CSV、完整备份；数据导入（支持合并 / 替换）

## 本地运行

```bash
node server.mjs
# 浏览器打开 http://localhost:4173
```

## 产品原则

- 月预算默认 1500 元硬约束，未来大额计划不得自动增加预算
- 预算是上限，不是鼓励花完的目标
- 优先保护现金流和未来选择权
- 评价消费行为，不评价人格
- 事实和建议必须分开，不编造账本数据

## 数据安全提示

数据只存在你打开它的那个浏览器里。换设备、清理浏览器数据都会导致数据丢失，请定期用「账本 → 导出备份」保存一份。
